# ADR 0028: 定数伝播・制御フロー簡約・死命令除去・ループ不変式移動を段階的に評価する

- **状態** 実装・部分採用
- **日付** 2026-11-21
- **関連** [ADR 0027（局所CSE）](0027-efflorescence-local-cse.md)、[ADR 0018（実ワークロードの計測）](0018-efflorescence-real-workload-measurement.md)

## 決定

JIT無効のVMで実行するMIR命令を減らす。まずインライン化後に値が確定した計算を畳み、その結果から不要な分岐と計算を取り除く。ループ不変式移動は、ここまでの変換後にも反復ごとに同じ計算が残る場合に評価する。各段階を単独で有効・無効にして、それまでに採用したパスへの上積みを測る。[現在の即値化・分岐融合・COPY除去](../../lib/wardite/efflorescence/optimizer.rb)

| 順 | 手法 | 最初に扱うケースと成立条件 |
|---|---|---|
| 1 | 定数伝播と定数畳み込み | 定数引数を渡したインライン化後のi32・i64演算を対象に、既知の入力から結果そのものを求める。幅ごとの折り返し、シフト量、比較の符号をWasmに合わせる。まずブロック内で行い、合流点へ広げる場合は到達する全経路で値が一致したときだけ定数とする。 |
| 2 | 制御フローの簡約 | 条件が確定した分岐を選ばれた経路に絞り、次の命令へのジャンプや無条件ジャンプの連鎖を省く。通常辺と例外辺の両方から到達不能と確認できた区間を取り除き、分岐先とハンドラのPCを更新する。 |
| 3 | 死命令除去（DCE） | 既存の未使用COPY除去を、結果がどこからも読まれない純粋な整数演算に広げる。除去で入力の最後の使用が消えたら、その定義も再評価する。副表の使用を数え、到達可能なロード、除算、ストア、呼び出し、throwは結果が不要でも残す。 |
| 4 | ループ不変式移動（LICM） | ループ中に値が変わらない入力だけから作る、trapしない純粋な整数式を入口の直前へ移す。単一入口のループから始め、入力が移動先で定義済みで、計算結果が全使用点に届くことを確認する。0回反復する経路の既存値を壊さないよう、必要なら専用の一時スロットを使う。 |

たとえば、インライン化でフラグが定数になれば、比較を畳み、片側の分岐を消し、その比較だけに渡していた計算も消せる。この順に評価すると、定数畳み込みが何件成立したかと、最終的に何回のディスパッチを省けたかを区別できる。LICMではループを1回通るごとの削減分と、入口で計算する費用を両方数える。

## 検証と採用条件

- 定数の境界値、値の異なる合流、分岐の連鎖、catchからだけ到達するブロック、結果を捨てる範囲外ロード・ゼロ除算、0回・1回・多数回のループを検証する。各段階でレジスタと分岐先を検証し、パスの有無で出力、trapの順序、trap直前までの書き込みを照合する。キャッシュ復元でも同じケースを実行する。
- インライン化した小関数では最適化後のMIRを確認し、Base64、PNG、篩ではJIT無効で対象ブロックの実行回数と動的ディスパッチの差を取る。計時はプロファイルを外し、同じ入力で有効・無効の順を交替する。小入力と大入力の全体時間、キャッシュミス時のMIR生成時間を併記する。
- 各段階で実ワークロードの実時間が再現して短縮するかを判定する。特にLICMは、頻出ループに移動可能な演算が残り、入口の費用を回収できる見込みがある場合に実装へ進める。

## 実装と適用範囲

各パスをインライン化後、スロット圧縮・レジスタ検証・バイト列融合の前に実行する。遅延準備と MIR2 生成の両方に同じ順序を使う。

| 段階 | スイッチ | 適用範囲 |
| --- | --- | --- |
| 定数伝播・畳み込み | `fold` | ブロック内で既知の整数演算を評価し、不変な定数スロットを参照する。合流・catch で伝播を止める。 |
| 制御フロー簡約 | `cfg` | 定数条件を解決し、ジャンプ連鎖、次命令へのジャンプ、到達不能区間を除去する。catch の入口は保守的にすべて残す。 |
| 死命令除去 | `dce` | 副表を含めて読まれないスロットを起点に、純粋な定義と入力の最後の使用を順次取り除く。 |
| 分岐経路ごとの死命令除去 | `exit_copy` | 同じ宛先を持つ複数の i64 バイト読み出し検査で、正常経路が直後に上書きする定数 COPY を分岐先で実行する。 |
| ループ不変式移動 | `licm` | 通常のフォールスルーからだけ入るループで、全入力が入口で定義済みの純粋な整数式を巻き上げる。宛先は単一定義で、全使用がループ内にある一時スロットに限る。 |

既定で有効にするのは Base64 decode の正常経路で効果が出た `exit_copy`。ほかのパスは `--mir-enable NAME` で個別に試せる。
